# Инструкция для AI-агента (Agent Instructions)

Привет, коллега-агент! 👋 
Этот проект является шаблоном (boilerplate/harness) для создания веб-презентаций на базе фреймворка **Astro**. Если пользователь (User) попросил тебя создать новую презентацию на базе этого проекта, строго следуй правилам ниже.

## 🏗 Архитектура проекта

1. **Ядро (Layout):** 
   - `src/layouts/PresentationLayout.astro` — главный слой презентации. В нем уже подключены стили, скрипты навигации (стрелки, свайпы) и прогресс-бар. Этот файл менять не нужно, если об этом не просят явно.
2. **Слайды (Контент):**
   - Все слайды должны создаваться как отдельные Astro-компоненты в папке `src/components/slides/`.
   - Рекомендуемый формат именования: `01-Title.astro`, `02-Intro.astro` и т.д.
   - Каждый слайд должен быть обернут в `<section class="slide"> ... </section>`.
3. **Сборка презентации (Pages):**
   - Файл `src/pages/index.astro` служит точкой входа.
   - Сюда нужно импортировать созданные компоненты слайдов и разместить их внутри компонента `<PresentationLayout>`.
4. **Темизация (CSS):**
   - Глобальные стили лежат в `src/styles/global.css`.
   - Цветовая палитра, свечения и **стилистика** (шрифты, скругления, отступы) вынесены в `src/styles/theme.css`. Если пользователь просит изменить цвета или стилистику презентации, редактируй переменные `:root` именно там.

## ⚙️ Генерация PDF

Проект поддерживает автоматический экспорт в PDF с помощью `Puppeteer` и `pdf-lib` через скрипт `to-pdf.mjs`.

- Скрипт **автоматически** подсчитывает количество слайдов (ищет классы `.slide`).
- Имя итогового PDF-файла берется из поля `"presentationName"` внутри `package.json`.

## 🚀 Workflow (Алгоритм работы агента)

Когда пользователь дает текст/контент для новой презентации, твой алгоритм действий должен быть следующим:

1. Ознакомься с контентом и разбей его на логические слайды.
2. Открой `package.json` и задай осмысленное имя для файла в поле `"presentationName"` (используй латиницу без пробелов, например `"Q3_Strategy_Report"`).
3. При необходимости, обнови CSS-переменные в `src/styles/theme.css` под цвета бренда пользователя.
4. Создай Astro-компоненты для каждого слайда в `src/components/slides/`, используя верстку (например, сетки `slide-cols` или стандартные центрированные блоки).
5. Импортируй созданные слайды в `src/pages/index.astro`.
6. Выполни команду `npm install` (если `node_modules` еще нет).
7. Если пользователь хочет посмотреть превью в вебе, запусти `npm run dev`.
8. Если пользователю нужен итоговый файл, сгенерируй PDF, выполнив команду `node to-pdf.mjs`. (Убедись, что перед этим нет запущенных серверов на порту 4195).
9. Отправь пользователю ссылку на сгенерированный PDF-файл.

Удачи в создании презентации! 🚀
